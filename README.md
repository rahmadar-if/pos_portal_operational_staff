## Fitur Unggulan
1. **Presensi Kamera & GPS Radius:** Foto selfie real-time dengan geofencing radius 50m.
2. **Direktori Staf & 1-Klik Direct WhatsApp:** Pihak pengelola gedung dapat langsung memanggil petugas aktif via WhatsApp.
3. **Checklist SOP Harian Digital & Foto Bukti:** Menggantikan kertas paraf toilet/patroli yang rawan manipulasi.
4. **Tiket Insiden & Panic Call:** Respon komplain cepat dengan transparansi status penanganan.
5. **Ekspor Laporan PDF/Excel 1-Klik:** Rekap kehadiran dan KPI siap kirim saat penagihan invoice.
6. **Arsitektur Multi-Tenant Terisolasi:** Sekat data gedung aman tanpa risiko data bercampur.

## Deployment ke Vercel
Proyek ini siap di-deploy secara instan (*Zero Config*) ke Vercel:
1. Hubungkan repositori GitHub ini (`pos_portal_operational_staff`) di dashboard Vercel.
2. Framework Preset: **Other**.
3. Root Directory: `./` (default).
4. Klik **Deploy**.
